How to use itSource code

Scammers can now copy a voice from a few seconds of audio. This page gives two people a shared secret so that, on a call, either of you can prove you're the real one. The secret never leaves your browser.

Set it up in a minute

  1. Be together, or on a call you already trust. Don't do this over the channel you're trying to protect.
  2. Both people scan the same QR code with any authenticator app — Google Authenticator, Authy, Microsoft Authenticator, 1Password, Bitwarden, Apple Passwords.
  3. Check your apps match the number shown above.
  4. Close this page. The secret only exists on your two phones now. Generate a fresh one if you want to set up another pair.

Using it on a call

"Something feels off. Read me the code." Open the app, read the six digits. If they match what's on your screen, it's them. If they stall, make excuses, or get it wrong — hang up and call back on a number you know.

More detail, and what this does and doesn't protect against →

One secret per pair. If you share one secret with your whole family, anyone in the family can pretend to be anyone else. Make a separate one for each pair of people.

No accounts, no cookies, no analytics, no server. Everything happens in your browser; you can save this page and run it offline. Standard TOTP (RFC 6238), so it works with any authenticator app.
